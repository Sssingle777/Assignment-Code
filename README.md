### Dijkstra

**问题描述：**

平面上有n个点（n<=100），每个点的坐标均在-10000～10000之间。其中的一些点之间有连线。若有连线，则表示可从一个点到达另一个点，即两点间有通路，通路的距离为两点间的直线距离。现在的任务是找出从一点到另一点之间的最短距离。

**输入：**

第1行为整数n，表示图中顶点的个数。

第2行到第n+1行（共n行），每行两个整数x和y，描述了一个点的坐标（以一个空格分隔）。

第n+2行为一个整数m，表示图中连线的个数。

此后的m行，每行描述一条连线，由两个整数i和j组成，表示第i个点和第j个点之间有连线（顶点按照从1开始数）。

最后一行：两个整数s和t，分别表示源点和目标点。

**输出：**

仅1行，一个实数（保留两位小数），表示从s到t的最短路径长度。

**算法思路：**

定义一个dist数组，存储起点s到i的距离，初始值设为INF（1e18）；

定义一个v数组，表示是否访问过点i，初始值为0（未访问）；

对每一个点通过遍历找到与他相邻的权重最小的邻接点，存入t，将t设为访问过，再对t的所有邻接点i遍历，dist[i]赋值为s到i与s到t再到i中的小值；

对所有点遍历完后得到的dist数组即为s到i的最短路径。

## 最小生成树——Prim

**问题描述：**平面上有n个点（n<=100），每个点的坐标均在-10000～10000之间。其中的一些点之间有连线。若有连线，则表示可以在这两个点之间修建道路，道路的长度为两点之间的直线距离。现在的任务是从已有连线中选择若干条道路，使得所有点之间能够相互连通，并且所选择道路的总长度最小。题目保证给定的连线可以使所有点连通。

**输入：**

第1行为整数n，表示图中顶点的个数。

第2行到第n+1行（共n行），每行两个整数x和y，描述了一个点的坐标（以一个空格分隔）。

第n+2行为一个整数m，表示图中连线的个数。

此后的m行，每行描述一条连线，由两个整数i和j组成，表示第i个点和第j个点之间有连线（顶点按照从1开始数）。

**输出：**

仅1行，一个实数（保留两位小数），表示连接所有点所需道路的最小总长度。

**算法思路：**

维护一个dist数组，表示生成树到点i的最短距离，初始值设为N（1e18）；

选定根节点1，令dist[1]=1；

开始选择n-1条边，首先遍历每个点，找到与1邻接且距离最短的点idx，将idx标记为访问过；

将距离加进ans中；

再次遍历所有与idx邻接的点i，若idx到i的距离小于dist[i]则更新dist[i]；

进入下一条边的选择。
